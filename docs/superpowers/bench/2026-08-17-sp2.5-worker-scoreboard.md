## Lessons (SP2.5)
1. The branch's own bugs showed up in its own build: fake `finish` aborts ×3 (T1, T4 fix, …), one false `completed` from a chat-template-misparsed tool call (T3 run 1), and 8 `max_turns` re-verify spins after a green suite. The new runner (finish tool, reply classification, stall detection) targets exactly these; the smoke run on the finished branch completed in 3 turns.
2. Never require a local model to write its own chat template's control tags literally (think/tool-call tags): LM Studio's Qwen3-coder parser eats them mid-argument. Build such strings by concatenation in code and tests, and say why in a comment.
3. Host mode sets HOME=worktree by design: user-site Python packages (pytest here) are invisible, so workers `pip install` into the worktree each run (23 MB, `git add -A` hazard). Pin `PYTHONUSERBASE` in the brief (or fix in the harness) and exclude the cache dirs locally.
4. Integration tasks (T6 main() refactor, T9 resume CLI) still land with qwen when the brief inlines exact code and binding notes; each needed 1–2 small fix rounds, no Sonnet escalation this time.
5. Fix briefs that inline the exact old/new text converge in one round (T2, T4, T6-fix2, T11-fix2 ≤ 30 turns); the one that described a change in prose (T9 fix1: "remove local imports") left work behind.

How this relates to savings

Recorded worker input + output tokens are a proxy for work offloaded from the orchestrator. These are not measured net frontier-token savings: tokenizers and execution paths differ, repeated input context is included, and orchestration/review tokens are not subtracted. All runs with complete recorded usage contribute, including rejected runs; accepted work is shown separately. Missing usage is excluded; providers that omit usage may have recorded zeros. Totals update when usage is written at run end.
